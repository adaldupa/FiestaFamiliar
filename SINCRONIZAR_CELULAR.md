# Controlar la TV desde el celular

1. En la computadora, dentro de esta carpeta, ejecuta `python3 servidor_local.py` (Windows: `py servidor_local.py`). Si otro servidor ocupa 8080, detenlo primero con Ctrl+C.
2. Abre `http://127.0.0.1:8080/index.html` en la computadora con el perfil que contiene tu sesión. Recarga nuevamente si todavía ves la versión antigua.
3. Busca **CELULAR + TV · MISMA WI-FI**. Abre en tu celular el enlace que aparece allí. Puedes introducir manualmente el código privado del conductor.
4. En la TV abre el enlace terminado en `publico.html`. Ese enlace no lleva código.
5. Deja la terminal y computadora encendidas. Celular y TV deben estar en la misma red, sin aislamiento de invitados. No necesitan Internet.

GitHub guarda el código; la computadora sincroniza el juego. La dirección `127.0.0.1` no sirve para conectarse desde otro aparato: utiliza la IP indicada por el servidor. No abras puertos del router. Las edades y el código pertenecen al conductor; no proyectes ese panel.

Consulta README para recuperación, revisiones simultáneas, copias, modo individual y pruebas.
